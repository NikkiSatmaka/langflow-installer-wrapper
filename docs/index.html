Langflow Web for Windows, macOS, and Linux

Install Langflow Web 1.11.4 with one click. No Python or package manager needed.

Download for Windows
~56 KB · Windows 10 / 11

How to install

1
Download the zip

Click the button above to get the installer.

2
Extract the zip

Right-click and select Extract All, or open it in File Explorer and drag the files out.

3
Double-click Install Langflow.bat

A menu will appear. Press I and hit Enter. The script handles everything.

What the script does

  • Installs uv (a fast Python package manager)
  • Downloads Python 3.12
  • Creates a virtual environment in %USERPROFILE%\langflow\
  • Installs Langflow 1.11.4
  • Creates desktop shortcuts (Langflow Web.lnk and Stop Langflow.lnk)
  • Adds the Langflow icon to the launch shortcut

How to run

1
Find the Langflow Web shortcut

Look for Langflow Web.lnk on your desktop. The installer created it for you.

2
Double-click the shortcut

A minimized terminal window will open with the server logs. A second window will guide you through startup.

3
Wait for your browser

The launcher opens your browser at http://127.0.0.1:7860 automatically once Langflow is ready.

How to stop

1
Double-click Stop Langflow.lnk

Find it on your desktop. It will close the Langflow server for you.

⚠️ Keep the minimized terminal window open — The Langflow server runs in that window. Closing it will stop the server and the browser page will stop working.

Download for Linux
~32 KB · Any modern Linux distribution

How to install

1
Download the zip

Click the button above to get the installer.

2
Extract the zip

Right-click and select Extract Here, or run unzip langflow-installer-linux.zip in a terminal.

3
Run Install Langflow.sh

If your file manager lets you, double-click and choose Run in Terminal. Otherwise, open a terminal in the folder and run bash Install\ Langflow.sh. Press I and hit Enter.

What the script does

  • Installs uv (a fast Python package manager)
  • Downloads Python 3.12
  • Creates a virtual environment in ~/langflow/
  • Installs Langflow 1.11.4
  • Creates desktop shortcuts in your app menu and on your desktop for both starting and stopping Langflow
  • Adds the Langflow icon to the launch shortcut

How to run

1
Find Langflow Web in your app menu

Look for Langflow Web in your application menu under Development. Or find langflow.desktop on your desktop.

2
Launch Langflow

Click the app menu entry or double-click the desktop shortcut. A terminal will open, start the server, and automatically open your browser at http://127.0.0.1:7860.

3
Press Enter to dismiss

After the browser opens, press Enter in the terminal to close it. The server keeps running in the background.

How to stop

1
Find Stop Langflow in your app menu

Look under Development in your application menu, or find stop-langflow.desktop on your desktop.

2
Double-click to stop

A terminal will open and close the Langflow server for you.

⚠️ If double-click opens the file in a text editor — Right-click the file, go to Properties > Permissions, and check Allow executing as program. Then double-click again and choose Run in Terminal.
